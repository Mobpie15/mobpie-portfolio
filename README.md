# Mobpie — Independent Full-Stack Web Engineer & Designer

> Bespoke digital flagships, high-ticket brand remakes, and high-performance web engineering.

## Overview
Mobpie is the personal engineering portfolio of an independent full-stack web engineer and creative designer based in India, specializing in crafting ultra-fast (<0.4s load), visually stunning, and high-converting digital flagships.

## Key Highlights
- **Obsidian Dark Luxury Theme**: Custom typography, glassmorphism, and minimal clean aesthetics.
- **Beat-Synchronized Waveform**: Real-time Web Audio API FFT frequency analyzer and RMS energy mapping directly to a smooth Three.js silk wave mesh.
- **Full-Stack Engineering**: Frontend interfaces, custom backend architectures, REST/GraphQL APIs, and headless CMS integrations.
- **Live Concept Showcases**: Real Retina Mac Safari browser mockup frames presenting Amazon Atelier and Atelier Ora.
- **Direct 1-on-1 Hotline**: Immediate WhatsApp and Direct Email client booking funnel.

## Tech Stack
- **Frontend**: HTML5, CSS3, Modern Vanilla JavaScript (ES6+)
- **3D & Audio**: Three.js (r128), Web Audio API (FFT Analyser, GainNode, AudioContext)
- **Hosting**: Vercel Edge Network (Sub-50ms TTFB worldwide)
